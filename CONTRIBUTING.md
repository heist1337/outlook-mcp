# Разработка

Python 3.12, uv и обычный Git. Тесты используют синтетические данные; Exchange,
пароли и корпоративный VPN для их запуска не нужны.

```bash
uv sync --locked
uv run --with ruff==0.17.3 ruff check src tests examples
uv run pytest
uv build
```

Изменения присылать через pull request. В issues и fixtures использовать
`example.com`, вымышленные сообщения и адреса. Не добавлять реальные `.env`,
выгрузки Exchange, токены, cookies, письма, приглашения, checkpoints или receipts.
Проверки живого подключения выполнять только на своём ящике и ограниченными чтениями.
Изменения рабочих данных не являются частью автоматической проверки проекта.
